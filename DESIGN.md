# CodeNebula visual world

## Thesis
Light studio canvas with one loud signal accent (coral) and a cool cyan secondary — Plata-like energy for a tech studio: breathable, colorful, confident.

## Palette
| Token | Hex | Role |
|-------|-----|------|
| canvas | `#F4F6FA` | Page ground |
| surface | `#FFFFFF` | Soft panels |
| ink | `#12141A` | Primary text |
| muted | `#5C6470` | Secondary text |
| coral | `#FF4D2E` | CTA / signal |
| coral-soft | `#FFE6E0` | Pills / tints |
| cyan | `#00B4D8` | Secondary accent / marks |
| cyan-soft | `#D9F6FC` | Soft chips |

## Type
- Display / UI: **Sora** (semibold heads, tight tracking)
- Body: **Manrope**
- No ALL-CAPS eyebrows

## Layout
- Light page; full-bleed hero with soft mesh + optional photo
- Cardless service grids (spacing over borders)
- Sticky about gallery kept; light frames
- Rounded CTAs ~14px; coral solid fills

## Anti-patterns for this world
- Near-black full-page backgrounds
- Purple/indigo SaaS defaults
- Dense card kits with identical shadows
- Heavy blur glass chrome
